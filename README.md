# Site

This is my site

Clone:

```sh
git clone https://www.github.com/ChrisDonovan307/site.git
cd site
```

Install:

```sh
pnpm install
```

Development:

```sh
pnpm run dev
```

Build and preview:

```sh
pnpm build
pnpm preview
```
